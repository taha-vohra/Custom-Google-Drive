# 🚀 Custom Google Drive

A custom-built Google Drive clone developed as a part of a college assignment. This project allows users to **upload, manage, and organize their files** securely using a web interface. Built with modern web technologies including **TypeScript**, **Express.js**, **PostgreSQL**, and **Sequelize ORM**.

## 🌟 Features

- 📁 Upload, delete, and organize files
- 👤 User authentication and authorization
- 🔒 Secure file handling
- 💾 PostgreSQL database integration using Sequelize ORM
- ⚙️ RESTful API architecture
- 🧪 Modular code with room for future expansion

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Language:** TypeScript
- **Database:** PostgreSQL
- **ORM:** Sequelize
- **Authentication:** JWT (or mention your auth strategy)
- **File Handling:** `multer` (or your preferred package)
